# Northstar IT Operations & Support Lab

## Project Overview

Northstar IT Operations & Support Lab is a hands-on IT support and systems administration portfolio project designed to simulate the day-to-day responsibilities of an IT Support Technician.

The lab focuses on troubleshooting, Windows administration, networking, Microsoft 365, identity management, PowerShell, security, and IT documentation.

## Simulated Environment

- Company: Northstar Solutions
- Employees: 25
- Operating System: Windows 11
- Environment: Microsoft 365 and simulated IT infrastructure
- Role: Junior IT Support Technician

## Project Objectives

- Troubleshoot Windows operating system issues
- Diagnose network connectivity problems
- Practice user and account administration
- Explore Microsoft 365 administration
- Learn identity and access management concepts
- Use PowerShell for system diagnostics
- Document incidents and resolutions
- Maintain an IT asset inventory
- Develop a troubleshooting knowledge base

## Lab Modules

1. Windows Troubleshooting
2. Networking
3. User Account Management
4. Microsoft 365 Administration
5. Microsoft Entra ID
6. PowerShell
7. Security and Incident Response

## IT Support Operations Application

The project will include an IT support dashboard for managing:

- Incident tickets
- Employees
- IT assets
- Knowledge base articles
- Ticket priorities and statuses
- Incident reporting
